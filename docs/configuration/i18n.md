## 🌍 Localization

The replies the bot sends on behalf of the Chums additions (billing, top-ups) are localized. Upstream messages (help, configuration, provider errors) are English.

Translations live in [`locales/`](../../locales/), one YAML file per locale (`en.yml`, `ru.yml`, …), and are embedded into the binary at build time. The bot currently ships `de`, `en`, `es`, `fr`, `id`, `pt`, `ru` and `sr`.


### Which locale a user gets

Matrix account data is private to its user, so the bot cannot read a user's language preference. Instead, the user's client declares it by sending a `cc.chums.set_user_locale` event into any room shared with the bot:

```json
{
  "type": "cc.chums.set_user_locale",
  "content": { "locale": "ru" }
}
```

The sender of the event is the user whose locale it is. The bot keeps the latest declared locale per user in memory and replies to that user in it. A regional variant maps onto its language (`pt-BR` → `pt`); a language without translations is ignored, and the user stays on the fallback locale.

Users who have not declared a locale get `i18n.fallback_locale`. The map is not persisted: after a restart every user is back on the fallback locale until their client sends the event again (the Chums client does so on start-up).

Replies addressed to a specific user (a chat command, the "balance too low" message, the top-up confirmation to whoever paid) use that user's locale, even in group rooms.


### Configuration

```yaml
i18n:
  fallback_locale: en
```

| Key | Meaning |
|---|---|
| `fallback_locale` | Locale of the replies to users whose client has not declared one. Must match one of the files under `locales/` exactly. Defaults to `en`. |

The key can be overridden with the `BAIBOT_I18N_FALLBACK_LOCALE` environment variable. Startup fails when the value is not one of the shipped locales.


### Adding a locale

1. Copy `locales/en.yml` to `locales/<code>.yml` and translate the values. Keep the `%{name}` placeholders: they are substituted at runtime, and the tests fail when a locale lacks a key or a placeholder of the English file.
2. Rebuild. There is nothing to configure: the file is picked up by the build and the locale becomes available to `cc.chums.set_user_locale` and `fallback_locale`.

A key missing from a locale falls back to English, so a partially translated file still produces complete replies.
